# 次のバージョン（1.1）で入れること

App Store の審査（1.0.1）が通ったあとに作る。審査中のビルドには入れない。
決めた日：2026-11-11（運営者と相談済み）

## 1. 「練習の記録」を見せる（見た目より実績で判断されるように）

- 紹介カード（クイックマッチの通話前の画面）とプロフィールに「練習の記録」を目立たせて出す
  - **完走率**：10分を最後まで話しきった割合（例「完走率 95%」）。割合なので始めたばかりの人も公平に評価される。10分通話が5回未満の人は「はじめたばかり」と表示
  - **最近30日の練習日数**（例「この30日で12日練習」）。古参が有利になり続けないよう期間を区切る
  - 10分通話の合計回数は小さく添える
- 紹介カードの順番を「練習の記録 → 自己紹介 → 写真（小さめ）」にして、写真が第一印象にならないようにする
  - 写真は隠さない（Apple の「通話前に相手がわかる情報を見せる」条件のため）
- 入れないもの：通話後の「また話したい」や星の評価（いいねと同じで人気の差が生まれ、SNSにしない方針とぶつかる）

## 2. 信頼スコアの見直し

- 数字は今までどおり本人にしか見せない（他の人には出さない）
- **計算と保存をサーバー側に移す**（今はアプリ側で計算して private/state に保存しており、本人が書き換えられる）
  - 途中終了の減点・10分完了の加点（1日5点まで）・違反の減点を、サーバーの通話記録と運営の判断から計算する
- **「スコアの低い人どうしをマッチさせる」はやらない**（`TRUST_RESTRICTED_BELOW` は定義だけで未使用。削除するか用途を変える）
  - 理由：利用者が少ないうちは相手がいなくなり抜け出せない／問題のある人が一か所に集まる／2回途中で切るだけで基準を下回る
- 代わりに「時間と順番」で調整する
  - 10分以内に自分で切る：−10、クイックマッチ30分停止（今と同じ）
  - 短期間にくり返す：停止を 30分 → 2時間 → 1日 とのばす
  - スコアが低め：誰とでもマッチはするが、待っている人が多いときは後回し（スコアの高い人が先）
  - 回復：10分話しきるたびに +1（1日5点まで）。ちゃんと話せば必ず戻れる
  - 悪質な違反：運営の確認で利用停止（今と同じ）

## 3. スキップのしすぎを抑える

- 紹介カードで見た目だけで次々スキップする人が出ないように、スキップが多い人はマッチしにくくする（後回し）
- 本人には「スキップが多いと、マッチしにくくなります」と表示する

## 4. 出会い目的への対策（2026-11-11 決定）

方針：**最初から口説くのは禁止。何度も話して仲良くなった後の関係は本人どうしの自由**。様子はレビューや通報を見て見直す。

- ルール：初対面での恋愛・出会い目的の接触を**全員に対して**禁止（初めての通話で口説く、容姿の話を続ける、会おうと誘う、しつこく連絡先を聞く）。お互いにフォローし合った人どうしの関係にはアプリは口を出さない
  - 通報理由「恋愛・出会い目的のアプローチ」を全員が使えるように（今は「語学のみの相手へ」限定の文言）
- 「語学のみ」バッジはなくす（「バッジがない人は口説いてよい」というサインになり、付けていない人が狙われやすいため）。設定・プロフィール・マッチング条件・ガイド・FAQ から外す
- 連絡先：通話の中でお互いの合意で交換するのは自由。プロフィールへの記載は今までどおり禁止。しつこく聞くのは禁止行為
- 写真：禁止しない。代わりに紹介カードの主役を**声**にする（自己紹介の音声を大きく表示して再生できるように）。並び順は「練習の記録 → 声 → 自己紹介 → 写真（小さめ）」
- ずっと入れないもの：性別・年齢での絞り込み、「近くの人」などの位置機能、見た目の評価・いいね

参考：Tandem は規約で「出会い系ではない」と明記し口説く行為を禁止。顔写真必須・性別表示・位置での絞り込みが物色する使い方を招くという指摘がある。
