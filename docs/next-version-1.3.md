# Tentalk 1.3 計画：「誰かが相手を探しています」通知

人が少ない時期でも、時間の約束なしにつながれるようにする。決まった「通話タイム」は作らない（ルールのように見せない）。

## 仕組み（実装済み、まだ本番には出していない）

- クイックマッチを始めて、待っている人がいなかったら、アプリが一度だけ `/api/call-wake` を呼ぶ。
- サーバー（`src/server/wake.ts`）が、その検索でつながれる人を最大5人選んでプッシュ通知を送る。
  - 言語交換なら「自分の学習言語のネイティブで、自分の母語を学ぶ人」、練習仲間なら「同じ言語を学ぶ、母語が違う人」。
  - いまアプリを開いている人・通話中の人には送らない（開いている人は通常の検索でつながる）。
  - 設定でオフにした人、どちらかがブロックしている人には送らない。
  - その人の現地時間で 23 時〜8 時は送らない。
  - 受け取るのは 1 人 3 時間に 1 回まで。送る側も 10 分に 1 回まで（`wake/{uid}` に記録）。
  - 通知には誰が探しているかを書かない。
- 通知を押すと、そのモードでクイックマッチが始まる。
- 検索の待ち時間を 90 秒から 3 分にした（通知を見て開く時間のため）。
- 設定 →「誰かが相手を探しているとき」で切り替えられる（最初はオン）。
- ルールは `src/domain/wake.ts`、テストは `src/domain/__tests__/wake.test.ts`。

## 出し方

変更はすべてプログラム（JavaScript）だけなので、ストアの審査なしで届けられる。

1. 1.2 が承認されたら、サーバーと Web 版を本番に反映する（`/api/call-wake` が使えるようになる）。
2. iPhone 2 台（またはアカウント 2 つ）で、片方が検索 → もう片方に通知が届き、押すとつながることを確かめる。
3. EAS Update で 1.2.0 のアプリに届ける。
